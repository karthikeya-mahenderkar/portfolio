# Resume source

`resume.html` is the source of `public/Karthikeya-Mahenderkar-Resume.pdf`
(self-contained, with the Computer Modern font embedded).

To update the resume:
1. Edit the text in `resume.html`.
2. Open it in Chrome → Print → Destination "Save as PDF", Paper "Letter",
   Margins "Default", Scale 100%, "Background graphics" on.
3. Save over `public/Karthikeya-Mahenderkar-Resume.pdf`, then commit and redeploy.
